# 客户研究交付格式

## 目录

- 研究综合报告
- 主题证据块
- JTBD 地图
- 国内外比较
- 需求分析交接
- VOC 原话库
- Persona 与研究缺口

## 研究综合报告

```markdown
# 客户研究：[主题]

## 研究范围
- 决策目标：
- 目标用户：
- 市场模式：china-only / global-only / hybrid
- 时间范围：
- 已有材料：
- 新采集信源：
- 未覆盖范围：

## 执行摘要
- [结论 + 市场 + 置信度]

## 用户分群
- [可观察的分群依据，不补写人口属性]

## JTBD 地图
[使用 JTBD 地图格式]

## 主要主题
[使用主题证据块]

## 矛盾与边界
- [哪些用户、场景、版本或市场不符合主要结论]

## 需求机会
[使用需求分析交接格式]

## 研究缺口
- [未知问题、缺失用户和下一步验证方式]

## 来源
- [标题](URL) — 平台，发布日期，采集日期，市场标签
```

## 主题证据块

```markdown
### [主题]
**市场**：China / Global / Cross-market
**摘要**：
**频次**：在 X 个独立来源、Y 个数据点中出现
**强度**：高 / 中 / 低
**置信度**：高 / 中 / 低
**影响群体与场景**：

**代表原话**：
- “……” — [来源](URL)，日期，市场
- “……” — [来源](URL)，日期，市场

**反例或矛盾**：
**产品含义**：
```

频次只在相同市场和可比样本中计算。同一转载链或营销活动只计一次。

## JTBD 地图

| 市场 | 细分群体 | Job 类型 | Job 表述 | 触发事件 | 当前做法 | 期望结果 | 代表原话与来源 | 置信度 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| China |  | 功能/情绪/社会 |  |  |  |  |  | 高/中/低 |

每个 Job 必须关联具体市场、可观察的细分群体、至少一条逐字原话及其来源。跨市场 Job 分别列出中国与海外证据，不用单一市场材料补齐另一市场的置信度。

## 国内外比较

```markdown
## 中国与海外比较

### 一致问题
- [两个市场分别有哪些证据]

### 中国特有因素
- [平台、政策、渠道、支付、采购、文化或基础设施]

### 海外特有因素
- [当地平台、监管、渠道或行为]

### 不可直接迁移的结论
- [只在一个市场验证的假设]

### 下一步验证
- [目标市场、目标用户、方法和成功判据]
```

## 需求分析交接

每个候选需求使用以下结构，不直接输出确定方案：

```markdown
### 需求机会：[名称]
- 用户问题：
- 目标细分群体：
- 适用市场：
- 当前做法/替代方案：
- 触发事件：
- 期望结果：
- 支持证据：
- 反例或不适用场景：
- 置信度：高 / 中 / 低
- 产品约束：
- 建议验证指标：
- 待验证问题：
- 暂不包含：
```

交给 PRD 前明确区分：已经证实的用户问题、尚未证实的解决方案假设、必须满足的本地约束。

不要为了文案效果润色原话。需要改写时保留原文列，并另设“提炼表达”。

## Persona 与研究缺口

只有同一细分群体至少存在 5 个独立数据点时，才输出确定性 Persona。Persona 包含主要 JTBD、触发事件、痛点、期望结果、异议、替代方案和有来源的词汇。

证据不足时输出“临时用户假设”：

```markdown
### 临时用户假设
- 假设：
- 已有证据：
- 缺失证据：
- 可能的样本偏差：
- 最小验证计划：
- 推翻该假设的信号：
```
