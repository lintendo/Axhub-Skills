## 证据记录

为每条用于结论的材料记录：

| 字段 | 要求 |
| --- | --- |
| `market` | `china`、`global` 或具体国家/地区 |
| `platform` | 平台或材料名称 |
| `source_type` | 访谈、工单、评论、社区、投诉、招聘、官方、媒体等 |
| `url_or_asset` | 可复核 URL 或用户材料标识 |
| `published_at` | 原内容时间；未知时明确写未知 |
| `collected_at` | 采集时间 |
| `segment_signal` | 角色、行业、地区、公司规模、版本等可观察线索 |
| `verbatim` | 逐字引用，不做润色 |
| `context` | 触发引用的上下文 |
| `tags` | job-functional、job-emotional、job-social、pain、trigger、outcome、language、alternative、objection、competitor |
| `commercial_risk` | 品牌合作、导购、厂商自述或未知 |
| `independence_group` | 用于识别同源转载或同一营销活动 |
| `fact_inference` | `fact`、`inference` 或 `hypothesis` |

不要从公开昵称推断真实身份、性别、收入或公司。只有来源明确披露且研究确有必要时，才记录用户画像信号。

## 来源筛选漏斗

按以下顺序筛选每个候选来源：

1. **相关性**：内容是否来自目标用户或能直接说明目标问题、场景、替代方案或约束。
2. **可复核性**：是否存在原始 URL、材料标识、日期和足够上下文。
3. **时效性**：产品版本、政策和市场环境是否仍适用于研究时间窗。
4. **独立性**：是否只是转载、同一营销活动、同一用户重复发布或搜索摘要。
5. **身份与利益关系**：能否识别为真实使用者、厂商、媒体、KOL、导购或未知角色。
6. **具体性**：是否包含行为、场景、结果或逐字表达，而不是空泛立场。
7. **样本适配**：来源用户是否属于目标市场和细分群体。

根据筛选结果分级：

| 级别 | 使用方式 |
| --- | --- |
| `primary-evidence` | 直接支持主题：访谈原话、工单、具体评论、社区使用过程、可验证行为记录 |
| `constraint-evidence` | 支持事实或约束：法规原文、官方披露、采购文件、产品文档 |
| `supporting-signal` | 提供线索或背景：招聘、独立媒体、行业报告、代码仓库活动 |
| `hypothesis-only` | 仅形成待验证假设：厂商案例、KOL、匿名传言、单一市场类比 |
| `exclude` | 排除：无原始出处、需要按时间判断却无法确定时间、明显复制、与目标样本无关或疑似伪造 |

不要用多个 `supporting-signal` 代替缺失的客户原话。官方资料可以高置信证明政策或产品事实，但不能证明用户感受。

原内容时间未知时记录为 `unknown`。这类材料不得支持依赖版本、政策或市场时点的结论；用于其他主题时降低置信度并明确时间缺口。

## 独立性与去重

以下情况只算一个来源：

- 同一文章、新闻稿、发布会或数据报告的转载和摘要
- 同一用户在多个平台复制发布的内容
- 同一品牌活动下高度模板化的 KOL 内容
- 同一访谈、工单或评论被多个文档引用

以下可以算不同证据，但需说明相关性：

- 同一用户在不同时间描述不同阶段的体验
- 同一事件中来自不同角色的独立原话
- 不同平台出现相似问题，且能排除转载或统一投放

## 置信度

### 高置信度

- 至少三个独立来源，覆盖两种以上来源类型。
- 主题在同一目标细分群体中一致。
- 有具体场景或逐字原话，不只是选择题或转述。
- 关键证据时效适合当前产品和市场。

### 中置信度

- 两个独立来源，或来源集中在一种平台/一个细分群体。
- 观点由提示问题引出，或缺少完整上下文。
- 存在合理但尚未解释的矛盾。

### 低置信度

- 单一来源、匿名传言、厂商自述或无法复核的摘要。
- 结论依赖推断、旧材料或明显偏置样本。
- 在一个市场出现，尚未在目标市场验证。

置信度不是投票。一个详细的失败案例可以揭示重要风险，但仍需标记覆盖范围，不能声称其普遍发生。

## 样本偏差

检查：

- 评论和投诉偏向强烈体验，客服工单偏向问题。
- 社区偏向活跃、技术熟练或愿意公开表达的人。
- KOL、媒体和厂商案例可能存在商业关系。
- 搜索引擎排序受 SEO、平台可索引性和个性化影响。
- 城市、行业、年龄、设备、价格带和产品版本可能改变结论。
- 沉默用户、流失用户和未购买者通常被公开社区低估。

报告样本构成和缺口。不要使用“用户都”“市场普遍”等措辞，除非证据确实支持。

## 国内外并行规则

- 为中国和海外证据使用不同的 `market` 标签、样本计数和主题频次。
- 先分别综合，再比较共性与差异。
- 跨市场一致可提高对“问题可能具有普遍性”的信心，但不能替代目标市场样本。
- 只在海外出现的主题标记为迁移假设；只在中国出现的主题检查是否由本地平台、政策、渠道或样本造成。
- 不比较不同口径的互动量、评分或市场数据。

## 安全与合规

- 仅采集完成研究所需的公开信息或用户明确授权提供的材料。
- 尊重平台条款、robots、登录限制、速率限制和版权。
- 不绕过验证码、风控、付费墙或访问控制。
- Cookie、Token、API Key 和二维码登录状态属于秘密，不写入报告或对话。
- 默认只读，不代表用户执行点赞、评论、关注、发布或私信。
- 最小化个人信息；引用敏感经历时去除无关身份线索。
- 涉及健康、金融、未成年人、就业歧视等敏感领域时提高审查标准并避免个体归因。
- 政策与合规结论回溯官方原文；本技能不替代专业法律意见。
